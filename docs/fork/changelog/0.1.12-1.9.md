## 中文

### 新功能

- **提示词快捷方式**：把常用的提示词存成快捷方式，在输入框里输入 `;` 加名字就能展开。在设置 → 提示词快捷方式里新建、编辑和删除，也可以把选中的文字直接存成快捷方式。手机上可以在输入框里使用已有的快捷方式。
- **用默认浏览器打开 HTML 和 PDF**：桌面版里右键一个 HTML 或 PDF 文件，选「在默认浏览器中打开」。
- **Antigravity 账号按机器分组**：账号来自多台机器时，网页和手机的用量列表按机器分组，标出每个账号在哪台机器上；同一个账号在几台机器上都有时只列一次。只有一台机器时列表不变。

### 修复

- Antigravity：实例走网络代理时，账号额度也能正常读出来。
- 桌面版在 shell 配置（如 `~/.zshrc`）里设置 `T3CODE_TELEMETRY_ENABLED=true` 开启使用数据现在会生效。T3 Extend 默认仍然不收集使用数据。
- 主题工作室：用中文输入法时按 Esc 结束输入，不会再退出取色，也不会丢掉正在改的方案名。

### 上游同步

- 同步上游 T3 Code 到正式版 `v0.1.12`（209 个提交）。你会看到的变化：
  - 在 cmd+k 里可以直接对当前对话标为已处理、置顶、稍后处理等。
  - 拖动侧栏边缘可以收起和展开侧栏；终端有了切换上一个、下一个终端的快捷键。
  - 搜索时用双引号括起来的词会按整句查找。
  - 项目在 `t3.json` 里定义的 worktree 准备命令要先经人批准才会运行。从 T3 Code 导入的项目需要重新批准一次。
  - Workflows（设置 → Labs）的提问支持带说明的选项、必填理由和撤回。
  - 更多文件类型有了专门的图标。

## English

### Features

- **Prompt shortcuts**: save prompts you reuse as shortcuts and expand one by typing `;` and its name in the composer. Create, edit and delete them in Settings → Prompt shortcuts, or save selected text as a shortcut. On mobile, existing shortcuts work in the composer.
- **Open HTML and PDF files in your default browser**: in the desktop app, right-click an HTML or PDF file and choose "Open in default browser".
- **Antigravity accounts grouped by machine**: when accounts come from more than one machine, the usage list on web and mobile groups them by machine, and an account on several machines appears once. With one machine the list is unchanged.

### Fixes

- Antigravity: account quotas load when the instance uses a network proxy.
- On desktop, opting in to usage data with `T3CODE_TELEMETRY_ENABLED=true` in your shell profile (such as `~/.zshrc`) now takes effect. T3 Extend still collects no usage data by default.
- Theme studio: pressing Esc to finish IME input no longer leaves color picking or discards a scheme name you are editing.

### Upstream

- Synced upstream T3 Code to the `v0.1.12` release (209 commits). What you will notice:
  - cmd+k can settle, pin, snooze and more for the current thread.
  - Drag the sidebar's edge to hide and restore it; new shortcuts cycle through terminals.
  - A search in double quotes finds its words together.
  - Worktree setup commands a project defines in `t3.json` run only after a person approves them. Projects imported from T3 Code need approving once more.
  - Workflow questions (Settings → Labs) take described choices, required reasons, and can be withdrawn.
  - More file types have their own icons.
