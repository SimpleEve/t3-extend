## 中文

这是第一个带更新说明的版本。0.1.11-1.1 和 0.1.11-1.6 发布时没有写更新说明，所以下面列的是 0.1.11-1.0 以来的全部变化。

### 新功能

- **桌面版自动更新**（macOS 和 Windows）：应用会去 GitHub Releases 检查新版本，有新版本时在应用里提示，你确认后下载并安装。**0.1.11-1.6 及更早的版本需要手动装一次这个版本**（下载 DMG 或安装包，直接覆盖安装），以后就会自动更新。
- **Windows x64 安装包**（`T3-Extend-<版本>-x64.exe`）：安装包没有代码签名，SmartScreen 会提示"未知发布者"，安装步骤见 `docs/user/install.md`。可以和官方 T3 Code 装在同一台电脑上。
- **主题工作室**：有十套风格预设，每套都包含配色、字体和布局，可以在下拉框里单独换字体，也可以上传一张背景图。它和"外观"设置是分开的两个页面。
- **Antigravity 多账号**：可以添加多个 Antigravity 账号，一个账号额度用完会自动切到下一个；每个 Antigravity 实例还可以设置一个网络代理。
- **在手机和浏览器里打开电脑上的本地网页**：转发改用上游的预览通道。omp、Antigravity 和 ACP Registry 里的 agent 启动的服务也能打开。从手机或浏览器打开的标签页由电脑在后台渲染，不会在电脑上弹出窗口；第一次使用时会显示后台浏览器的下载进度；电脑端窗口没有在绘制时会给出提示。
- **手机上长按网页链接**，可以选择用内置浏览器打开、用系统浏览器打开或复制链接；指向本机（localhost）的链接直接用内置浏览器打开。
- 更新弹窗里的更新说明跟随应用语言：中文界面只显示中文部分，其他语言显示英文部分。

### 修复

- 退出时如果有步骤卡住，最多 25 秒后会强制退出，不会再一直挂着。
- 桌面应用开着的时候，iPhone 的推送通知也能正常收到。
- 手机应用升级后不会再变回英文，底部标签栏也已经翻译。
- 补上了中文翻译：上游新增的问题追踪、已保存视图、设置变更等页面，以及时间线里服务器唤醒通知的摘要。
- 桌面安装包现在包含 LICENSE 和 NOTICE 文件（以前的 macOS 包里没有）。

### 上游同步

- 同步上游 T3 Code 到 `9cc4018c75`。界面文案改用上游的翻译方式，语言设置也合并成上游的那一个选项，原来选的语言会自动迁移过去。T3 Extend 的专有术语在中文界面里保持不变。

## English

This is the first release with release notes. 0.1.11-1.1 and 0.1.11-1.6 went out without them, so this list covers everything since 0.1.11-1.0.

### Features

- **The desktop app updates itself** (macOS and Windows): it checks GitHub Releases for a new version, tells you in the app, and downloads and installs it after you confirm. **Installs of 0.1.11-1.6 and earlier must install this version by hand once** (download the DMG or the installer and install over the old app); after that they update themselves.
- **Windows x64 installer** (`T3-Extend-<version>-x64.exe`). It is not code signed, so SmartScreen says "Unknown publisher"; the steps are in `docs/user/install.md`. It installs next to official T3 Code.
- **Theme studio**: ten style presets, each with colours, fonts and layout. Change fonts from a dropdown and upload a background image. It is a separate page from Appearance.
- **Several Antigravity accounts**: add more than one account and Antigravity switches to the next when one runs out of quota. Each Antigravity instance can also use a network proxy.
- **Open your computer's local web pages from a phone or browser**: forwarding now uses upstream's preview tunnel, and servers started by omp, Antigravity and ACP Registry agents can be opened too. Tabs opened from a phone or browser render in the background on the computer instead of popping up a window there. The first use shows the background browser's download progress, and you are told when the computer's window is not drawing.
- **Long-press a web link on the phone** to open it in the built-in browser, open it in the system browser, or copy it. Links to the computer itself (localhost) open in the built-in browser.
- The release notes in the update dialog follow the app language: the Chinese interface shows the Chinese section, every other language shows the English one.

### Fixes

- A quit that gets stuck now ends after at most 25 seconds instead of hanging.
- iPhone push notifications keep arriving while the desktop app is open.
- The phone app no longer falls back to English after an update, and the bottom tab bar is translated.
- Chinese translations for upstream's new pages (issues, saved views, settings changes) and for the server wake-up summaries in the timeline.
- Desktop packages now include the LICENSE and NOTICE files (earlier macOS packages did not).

### Upstream

- Synced upstream T3 Code to `9cc4018c75`. The interface text now uses upstream's translation system, and the language setting is upstream's single option; the language you picked carries over. T3 Extend's own terms stay as they were in Chinese.
