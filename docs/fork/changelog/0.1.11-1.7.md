## 中文

### 新功能

- 桌面版（macOS 和 Windows）会自动检查更新：它读取 GitHub Releases 上的新版本，在应用里提示，由你确认后下载并安装。**0.1.11-1.6 及更早的安装需要手动装一次这个版本**（下载 DMG 或安装包，覆盖安装），之后才会自动更新。
- 新增 Windows x64 安装包（`T3-Extend-<版本>-x64.exe`）。它没有代码签名，SmartScreen 会提示“未知发布者”，安装步骤见 `docs/user/install.md`。
- 更新弹窗里的更新说明跟随应用语言：中文界面只显示中文部分，其他语言显示英文部分。

### 修复

- 桌面安装包现在带上了 LICENSE 和 NOTICE 文件（之前的 macOS 包也没有）。

## English

### Features

- The desktop app (macOS and Windows) now checks for updates: it reads new versions from GitHub Releases, tells you in the app, and downloads and installs after you confirm. **Installs of 0.1.11-1.6 and earlier must install this version by hand once** (download the DMG or the installer and install over the old app); after that they update themselves.
- New Windows x64 installer (`T3-Extend-<version>-x64.exe`). It is not code signed, so SmartScreen says "Unknown publisher"; the steps are in `docs/user/install.md`.
- The release notes in the update dialog follow the app language: the Chinese interface shows the Chinese section, every other language shows the English one.

### Fixes

- Desktop packages now include the LICENSE and NOTICE files (earlier macOS packages did not).
