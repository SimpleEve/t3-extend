## 中文

### 新功能

- **消息书签**：可以给整条消息或其中一段文字加书签。书签显示在侧栏、右侧面板和手机上，点一下就跳回原处。
- **Antigravity 多账号用量**：用量页按账号列出每个账号的额度。没在用的账号显示最后一次读到的数值，可以手动刷新，也可以在设置里让应用在后台低频读取。网页和手机都是紧凑的列表，会标出正在用的那个账号。
- **Antigravity 会话从第一轮起就能用实例里配置的 MCP 服务器**。实例设置里新增「使用全局 MCP 服务器」：打开后，这个实例改用终端 agy 的 MCP 配置和登录；开着它时，这个实例不再用来生成标题和提交信息。第一次 OAuth 授权仍然要在终端 agy 里完成。
- **主题工作室新增预设**：Editor、One Dark、Solarized、GitHub、Nord 和 Mochi。调好的预设可以另存成自己的方案并命名。

### 修复

- Antigravity：适配 agy 1.5.16 改名的登录存储开关，升级 agy 后不会再显示未认证；agy 1.5.15 的 JSON 格式额度报错也能识别，额度用完会照常切换账号；已保存的账号能正常续期。
- 从官方 T3 Code 导入数据时不会再整个失败。
- 设置页左侧导航和页标题恢复成中文。
- 服务器重启后自动续跑的通知改为显示 T3 Extend，并有中文。
- 输入框旁边的上下文圆环在部分对话里不显示，已修复。
- 主题工作室的颜色输入框：删字时不会再被自动改写。

### 上游同步

- 同步上游 T3 Code 到 `a7a6126a7d`（834 个提交）。你会看到的变化：
  - 新增 Workflows（默认关闭，在设置 → Labs 里打开），网页和手机都能用。
  - 设置里的环境页改成机器地图；可以从只读对话直接连接已关联的环境。
  - 一个项目可以包含多个仓库；Linear 支持多个账号和团队。
  - Mac 上可以用系统自带的 Apple 语音听写（设置 → 语音）。
  - HTML 预览宽度可以单独设置。
  - 侧栏头部的文件夹按钮现在既能选项目，也能添加项目，原来单独的「添加项目」按钮去掉了。
  - 助手回复下面的「改动文件」卡片去掉了，改动的文件在右侧的 diff 面板里看。
  - 手机端有大量修复：Android 切换语言立即生效、预览链接只打开 http/https、图片和相册等。
- 上游新加的 Labs「Agent 反馈」会把报告发给官方团队，T3 Extend 里不显示这一项。

## English

### Features

- **Message bookmarks**: bookmark a whole message or a passage in it. Bookmarks show in the sidebar, the right panel and on the phone, and take you back to the spot.
- **Per-account usage for Antigravity**: the usage view lists every account's limits. Accounts not in use show their last reading, with a refresh button and a setting that reads them now and then in the background. The list is compact on web and mobile and names the account in use.
- **Antigravity sessions get the instance's MCP servers from the first turn.** A new **Use global MCP servers** switch in the instance settings makes the instance use the terminal agy's MCP config and sign-ins; while it is on, that instance is not used for titles and commit messages. The first OAuth sign-in still happens in the terminal agy.
- **More theme studio presets**: Editor, One Dark, Solarized, GitHub, Nord and Mochi. Save your own version of a preset under a name.

### Fixes

- Antigravity: works with agy 1.5.16, which renamed its sign-in storage switch, so upgrading agy no longer leaves it signed out; agy 1.5.15's JSON quota error switches accounts again; saved accounts renew.
- Importing from official T3 Code no longer fails as a whole.
- The settings navigation and page titles are in Chinese again.
- The notice after the server restarts and resumes a turn names T3 Extend and is translated.
- The context ring next to the composer shows again in threads where it was missing.
- Theme studio colour fields keep what you type while you delete.

### Upstream

- Synced with upstream T3 Code at `a7a6126a7d` (834 commits). What you will notice:
  - Workflows, on web and mobile (off by default; turn them on in Settings → Labs).
  - The environments page is a map of your machines; connect to a linked environment from its read-only thread.
  - A project can cover several repositories; Linear supports several accounts and teams.
  - Dictation with Apple Speech on the Mac (Settings → Voice).
  - A separate width setting for HTML previews.
  - The sidebar folder button picks or adds a project; the separate Add project button is gone.
  - The changed-files card under assistant replies is gone; see changed files in the diff panel on the right.
  - Many mobile fixes, including Android language changes applying at once, local preview links opening only http and https, and image and gallery fixes.
- Upstream's Labs **Agent feedback** sends reports to the official team, so T3 Extend does not show it.
