## 中文

### 新功能

- **设备可见性**：用自建服务器时，每台电脑可以决定哪些设备能看到它：对所有设备可见、全部隐藏、对指定设备隐藏，或只对指定设备可见。看不到的设备列表里没有它，也登录不上。在设置 → 设备里修改，当前选择会显示在标题旁、设备列表和这台电脑的环境上。要先把自建服务器更新到这一版。
- **右侧面板分屏**：右侧面板可以向四个方向拆分，最多 2×2 四格，Files、Diff、Browser 等面板能并排放在对话旁边。
- **Files 面板显示软链**：文件树里能看到指向工作区外的软链并进去浏览，断开的软链会标出来；写入仍然只限工作区内。
- **omp 主题预设**：主题工作室里新增 omp 预设，深色和浅色各一套；对话里的工具调用显示成卡片，按运行中、成功、失败区分颜色。

### 修复

- 「添加项目」的路径框预填了 `~/`，直接在后面接着输入 `/tmp/项目` 这类绝对路径时，以前会建到主目录下的同名空文件夹里，现在会用你输入的绝对路径。
- Antigravity：每个用量窗口的重置倒计时各自正确，不再都显示成同一个；自动切号后会补读刚用完的那个账号；额度读不出来时会说明原因。

### 上游同步

- 同步上游 T3 Code 到正式版 `v0.1.13`（401 个提交）。你会看到的变化：
  - **Antigravity 不再默认读取额度。** 上游说明 Google 表示调用其内部接口读额度可能导致账号被标记，所以删掉了这部分。T3 Extend 保留了它，但改成每个实例的开关「读取 Google 额度」，默认关闭；更新后用量里看不到 Antigravity 的额度和多账号用量，需要的话在设置 → Provider → Antigravity 实例里打开，风险自负。账号池、手动切号和额度用完自动切号不受影响。
  - Antigravity 需要 1.5.1 或更新的版本。
  - 文件侧栏可以复制路径；设备面板里可以单独停止某个设备，或一次全部停止。
  - Claude 的设置关掉 Auto 模式时，权限菜单里的 Auto 会显示为不可用。
  - 低于完全访问的 agent 在 push 会触发仓库钩子时会先询问。

## English

### Features

- **Device visibility**: on your own server, each computer chooses which devices can see it: every device, none, all but some, or only some. A device that cannot see it does not list it and cannot sign in to it. Change it in Settings → Devices; the current choice shows beside the title, in the device list and on this computer's environment. Update your self-hosted server to this version first.
- **Split the right panel**: split it in any direction, up to a 2×2 grid, so Files, Diff, Browser and other panels sit side by side next to the chat.
- **Files shows symbolic links**: links that point outside the workspace show in the file tree and can be browsed, broken ones are marked, and writes still stay inside the workspace.
- **omp theme preset**: the theme studio has an omp preset in dark and light, and tool calls in the chat become cards colored by running, success and failure.

### Fixes

- The Add project path box starts with `~/`. Typing an absolute path such as `/tmp/project` straight after it used to create an empty folder of that name inside your home folder; it now uses the absolute path you typed.
- Antigravity: each usage window counts down to its own reset instead of all showing the same one, the account that just ran out is read again after an automatic switch, and an empty limits read says why.

### Upstream

- Synced upstream T3 Code to the `v0.1.13` release (401 commits). What you will notice:
  - **Antigravity quota is no longer read by default.** Upstream removed it because Google says reading quota through its internal API can get an account flagged. T3 Extend keeps it as a per-instance switch, **Read quota from Google**, off by default. After updating, Usage shows no Antigravity quota or multi-account usage until you turn it on in Settings → Providers → your Antigravity instance, at your own risk. Account pools, manual switching and switching when quota runs out work either way.
  - Antigravity needs version 1.5.1 or newer.
  - Copy paths from the file sidebar; stop devices one at a time or all at once from the Device panel.
  - Auto shows as unavailable in the permission menu when Claude's settings turn it off.
  - Agents below Full access ask before a push runs repository hooks.
